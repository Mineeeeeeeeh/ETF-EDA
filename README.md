# 네이버 ETF 분석

네이버 금융에서 제공하는 ETF 시세와 기본 정보를 수집·분석하는 프로젝트입니다.

## 분석 범위

- ETF별 현재가, 등락률, 거래량 및 거래대금 비교
- 자산운용사·기초지수·상장일 등 기본 정보 정리
- 기간별 수익률과 변동성 분석
- 관심 ETF의 성과를 비교할 수 있는 시각화

## 데이터

데이터 수집 범위와 이용 조건은 네이버 금융의 정책을 확인한 뒤 준수합니다. 분석 결과는 투자 권유가 아니며, 투자 판단과 그에 따른 책임은 이용자에게 있습니다.

## 실시간 대시보드

실시간 ETF 탐색 대시보드는 `sites/naver-etf-dashboard`에 있습니다. 운용사·시장·상품군별 분석, 다중 필터, 정렬, 종목 상세 조회를 제공합니다.
